Description
This is a Java console application for user registration and login. It validates username, password and South African cellphone number.

 Features
- Username validation: Must contain underscore (_) and max 5 characters
- Password complexity: 8+ chars, capital letter, number, special character
- Cellphone validation: +27 format using regex ^\+27[0-9]{9}$
- Registration and Login functionality
- JUnit 5 Unit Tests with Maven

How to Run
1. Clone repo
2. Open in NetBeans as Maven project
3. Run Main.java (console input only)
4. Run tests with mvn test
