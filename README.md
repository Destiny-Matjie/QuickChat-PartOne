# QuickChat - Part One

QuickChat is a Java messaging app that allows users to login, send messages, store messages, and view stored messages.

## Features
- User login with username and password validation
- Send messages
- Store messages in JSON file
- View stored messages
- Unit tests for messages

## How to Run
1. Open project in NetBeans / IntelliJ
2. Run QuickChat.java
3. Follow menu to login and send messages

## Tests
Run MessageTest.java and LoginTest.java to verify functionality.
